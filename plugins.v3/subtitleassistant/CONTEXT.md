# 字幕助手

MoviePilot 插件：字幕的搜索、下载、归属、落盘与记录管理。本词汇表约束插件代码、工单与文档使用的领域语言。

## Language

### 搜索与候选

**字幕来源**:
提供字幕搜索与下载的外部服务（站点聚合、OpenSubtitles、ASSRT）。
_Avoid_: 渠道、provider

**凭据**:
外部字幕源的长期鉴权秘密集合，是来源运行实例的构造期输入；区别于来源开关（是否启用）与来源状态（健康观测）。
_Avoid_: 密钥、口令

**搜索**:
查询字幕来源并汇总其返回候选及查询结果的业务活动，本身不决定候选是否准入、选择顺序或是否下载。

**候选**:
一次搜索返回的、可供选择下载的字幕结果。
_Avoid_: 结果项、条目

**下载句柄**:
候选对应的下载定位信息，形状由其来源定义。
_Avoid_: 下载凭证、定位符

**下载**:
针对一个已选定候选，获取字幕文件并完成解包、归属、保存与记录的业务处理。手动和自动是使用同一下载能力的业务方式，候选选择与失败后是否继续尝试由各自业务流程决定。

**准入**:
自动任务对候选的过滤判定（简中、翻译类型、宿主媒体匹配）。准入属于自动业务流程，人工选择不受自动准入限制。
_Avoid_: 过滤、筛选（泛指可用，指分叉点语义时必须用"准入"）

**手动搜索 / 自动搜索**:
手动搜索面向已整理的历史目标，由用户查看识别标注后选定候选；自动搜索由整理完成事件触发的任务发起，按自动规则准入、匹配并选择候选。两者使用同一搜索能力，候选的识别、选择及异常处置遵循各自业务规则。

**搜索会话**:
一次人工搜索的目标媒体与返回候选之间的短期关联，用于校验和解析用户后续选择。自动搜索不需要创建搜索会话。

### 任务与记录

**目标媒体**:
字幕所归属的已整理媒体，其身份与媒体路径不随字幕保存目录映射改变。

**字幕保存目录映射**:
媒体目录到字幕保存目录的对应关系，仅决定字幕文件的保存位置，不改变字幕归属的目标媒体；映射后的目录可以不包含视频文件。
_Avoid_: 媒体路径映射、历史路径修复（均不属于本概念）

**字幕文件路径**:
已保存字幕文件的实际位置，包含目录与文件名；后续修改字幕保存目录映射不会改变该文件的实际位置。

**任务**:
一次字幕获取工作的运行单元（自动触发或手动提交），以终态与原因码收尾。

**匹配记录**:
落盘成功的字幕文件及其归属信息的业务记录，支撑记录视图、改配与删除。匹配记录是业务产物，不是过程留痕。
_Avoid_: 审计记录、日志

**暂存库存**:
归属暂未确定的字幕暂存集；自动任务先查库存，命中即直接落盘，人工选定候选的任务直接处理该候选。
_Avoid_: 缓存（缓存指可丢弃的加速层）

**改配**:
将匹配记录及其字幕文件改绑到另一个目标媒体。
_Avoid_: 重定向、重绑定
