# 将字幕保存目录与媒体位置分离

重新设计前，路径映射表达“整理历史中的旧媒体目录到当前媒体目录”的换算，使字幕保存位置与媒体位置绑定。2026-10-01 确认将目录映射定义为“字幕保存目录映射”：只决定字幕文件的保存位置，不改变字幕归属的目标媒体，映射后的目录不要求包含对应视频；未配置映射或未命中规则时，保存到原媒体同目录。选择这一边界是为了支持独立的字幕保存目录，避免将保存字幕解释为媒体已经迁移。

## 已确认的行为边界

- 已有标准字幕只在本次字幕保存目录中检查；原媒体目录已有字幕不阻止向另一个保存目录下载字幕。
- 有明确的媒体目标信息且字幕保存位置可写时，允许保存字幕，不要求原媒体文件当前可访问。媒体文件存在性可以作为提示，不作为字幕下载门槛；自动任务与历史目标采用同一边界。
- 命中映射时，配置中的目标根目录必须存在，其下的相对目录允许自动创建。未命中映射时，要求原媒体目录存在，不自动创建该目录。
- 自动下载、手动下载、暂存库存命中后的落盘以及改配到目标媒体，共用字幕保存目录映射规则。尚未确定归属的暂存字幕仍保存在插件暂存区。
- 修改映射只影响后续落盘，不自动移动已有字幕，也不改写旧记录中的实际字幕文件路径。查看和删除已有字幕依据记录中的实际位置；显式改配才重新计算目的地并移动文件。
- 修改映射后，新保存目录没有字幕时，允许后续任务再次下载；旧保存目录中的副本保留。
- 移除映射对媒体路径的改写，不另行引入媒体路径映射。媒体身份与原始路径保持原意；修复历史媒体路径不属于本次设计范围。

## 目录规则与命名

保留完整目录段匹配、最长来源前缀优先、保留相对目录及只替换一次的规则。字幕仍按目标媒体的原文件主名和既有字幕命名规则命名；不增加通配符、正则、目录平铺或命名模板。

例如，媒体路径为 `/media/剧集/A/S01/E01.mkv`，映射为 `/media → /subtitles`，SRT 字幕保存到 `/subtitles/剧集/A/S01/E01.chi.zh-cn.srt`。目标媒体路径仍为 `/media/剧集/A/S01/E01.mkv`，不构造或检查一个代表媒体新位置的 `/subtitles/剧集/A/S01/E01.mkv`。

## 配置生效时机

- 任务开始执行时按最新配置确定并固定本次字幕保存位置，后续检查与写入使用同一位置。执行期间修改配置不影响该任务；排队但尚未执行的任务在启动时读取最新配置。
- 改配预览展示预计目的地；提交时核对当前配置计算的目的地。如果与预览不同，要求刷新预览，不直接移动到新位置。

## 失败与冲突

- 字幕保存目录已有标准字幕时跳过；检查后出现同名文件时报告冲突，不覆盖。
- 映射根目录不可用、目录创建失败或写入失败时，明确报告失败，不自动退回原媒体目录，也不尝试其他保存位置。
- “未命中映射时保存到原媒体同目录”仅是默认保存规则，不是映射失败时的回退规则。

## 旧配置与记录

沿用旧映射的来源目录与目标目录配置值，更新名称和说明为字幕保存目录映射，不要求用户重新填写。已有字幕文件和记录中的实际字幕文件路径保留；旧记录中的映射信息作为当时的历史快照，不按新规则重算，也不以旧映射后的路径推定媒体当前位置。

## 关键验收场景

| 场景 | 预期行为 |
| --- | --- |
| 命中映射，原视频不可访问，映射目标根存在且可写 | 允许保存；缺失的相对目录自动创建 |
| 原媒体目录有标准字幕，映射保存目录没有 | 允许继续向映射保存目录下载 |
| 映射保存目录已有标准字幕 | 跳过，不覆盖 |
| 命中映射，但目标根不存在 | 失败，不创建根目录，不回退到媒体目录 |
| 未命中映射，原媒体目录存在且可写 | 保存到原媒体同目录，不要求视频文件存在 |
| 未命中映射，原媒体目录不存在 | 失败，不自动创建媒体目录 |
| 任务执行期间修改映射 | 本次继续使用已固定的位置，后续任务使用新配置 |
| 改配预览后修改映射，导致目的地变化 | 要求刷新预览，不移动文件 |
| 修改映射后删除旧记录对应的字幕 | 使用记录中的实际字幕文件路径 |
| 检查通过后，同名目标文件被其他任务创建 | 报告冲突，不覆盖该文件 |

## 实施记录（2026-10-01）

以上设计经逐轮确认后已实现，并完成以下配套更新：

- `SubtitleDestination` 单独保存冻结的字幕目录和命中规则，替代携带媒体事实副本的 `ResolvedTarget`。任务、候选尝试、库存和改配不再改写媒体路径；落盘事件分别携带原媒体路径和实际字幕文件路径。
- 旧 `path_mappings` 配置及记录路径保持兼容，不执行文件搬迁或记录路径重算。新任务增加可空的 `subtitle_directory` 字段，旧任务缺失该字段仍可读取。
- 宿主保存配置会调用插件初始化；仅映射变化时原位更新规则，保留运行任务与队列。其他配置变化及显式重启仍遵循原有生命周期。
- 单条和批量改配提交均要求 `expected_final_subtitle_path`，从预览结果取得。目的地变化时拒绝提交；前端刷新预览，等待用户重新确认，不自动重试移动。
- 前端配置、任务和记录详情采用新的路径语义，联邦组件构建产物已更新。
